Maîtrisez Claude, de la première conversation
aux agents autonomes

Une formation complète, gratuite et en français sur tout l'écosystème Claude d'Anthropic : le chat, l'art du prompt, Cowork, Claude Code, l'API et les intégrations. Cours structurés, exercices corrigés, quiz interactifs et ressources officielles — adaptés à votre niveau.

1. Choisissez votre niveau

Votre choix est mémorisé et filtre le contenu de tous les modules : chaque niveau inclut le contenu des niveaux précédents. Vous pouvez en changer à tout moment depuis l'en-tête du site.

2. Suivez le parcours

Les modules sont conçus pour être suivis dans l'ordre, mais chacun est autonome. Votre progression est enregistrée localement dans votre navigateur (rien n'est envoyé sur un serveur).

🧭

1. Fondamentaux

Qu'est-ce que Claude, les modèles, les offres, les tokens et la fenêtre de contexte. Le socle pour tout le reste.

 💬

2. Claude Chat

Tirer le maximum de claude.ai : conversations, fichiers, Projets, Artéfacts, recherche, styles et mémoire.

 ✍️

3. L'art du prompt

La compétence n°1 : formuler des demandes claires, structurées et itératives, du prompt simple au méta-prompting.

 🤝

4. Cowork & équipe

Claude comme collègue de travail : tâches sur vos fichiers, skills, connecteurs et usage en entreprise.

 ⌨️

5. Claude Code

L'agent de code dans votre terminal : installation, CLAUDE.md, permissions, git, hooks, MCP, sous-agents et CI.

 🔌

6. API & développeurs

Construire avec Claude : Messages API, tool use, streaming, vision, prompt caching, batchs et Agent SDK.

 🧩

7. Intégrations

Claude partout : apps mobile et desktop, Claude in Chrome, Slack, et le protocole MCP côté utilisateur.

 🛡️

8. Bonnes pratiques

Utiliser l'IA de façon fiable et responsable : vérification, données sensibles, limites, gouvernance.

 📚

Bibliothèque

Vidéos, documentations officielles, glossaire français de l'IA générative et liens pour aller plus loin.

Comment cette formation est construite

🎓 CoursDes leçons courtes et concrètes, avec des exemples copiables (prompts, commandes, code) que vous pouvez tester immédiatement dans Claude.
💪 ExercicesChaque module propose des exercices pratiques par niveau, avec une solution détaillée masquée — essayez avant de regarder !

📈 ProgressionMarquez vos leçons terminées ; votre avancement s'affiche sur cette page. Tout reste dans votre navigateur.
💡 Conseil de départ Si vous ne savez pas par où commencer : choisissez le niveau Débutant, faites les modules 1 à 3 dans l'ordre, puis passez au niveau Intermédiaire et refaites le tour — de nouvelles leçons apparaîtront dans chaque module.
